# DIET MANAGER API


API for daily diet control.
The goal of this project is to allow the management of users and daily meals, tracking whether each meal is inside or outside the planned diet.

### Base URL

http://localHost:3333


### Endpoints

users: 

POST /users

GET /users

meals:

POST /meals

GET /meals

GET /meals/:id

PUT /meals/:id

DELETE /meals/:id
